The Undub Mod (Dub Names) changelog
========================================
Changelog v1.0
========================================

=====================
Changed Digimon Names
=====================
Every digimon has been reverted to their original in-game Dub name EXCEPT the following:

- Kerpymon (Good) / (Blk) -> Cherubimon (Good) / (Evil)
- Argomon -> Algomon
- Creepymon -> Daemon
- Kurisarimon -> Chrysalimon
- Diaboromon -> Diablomon
- Lotosmon -> Lotusmon
- Socerimon -> Sorcerimon
- Dragomon -> Dagomon
- Merukimon -> Mercurymon
- Sistermon Ciel -> Sistermon Noir
- GroundLocomon -> GrandLocomon
- Bao/Savior/Huckmon -> Bao/Savior/Hackmon
- Lucemon Rival -> Lucemon Larva
- MedicalGallantmon -> MedievalGallantmon
- DoruGreymon -> Doruguremon

some name typos were fixed (Aguman Expert -> Agumon Expert)

=====================
Changed Dialogue
=====================
Dialogue has been changed to represent the dub names of Digimon, and dub terms (digivolve instead of evolve etc). Other fixes/changes:
- their alive, but unresponsive -> they're alive, but unresponsive
- Rebellions -> Rebels
some typos were fixed. 

=====================
Changed Terms
=====================
Digimon stages, terms and mechanic names were changed to their dub names with the exception of Xros and Degenerate.
- Adult -> Champion
- Perfect -> Ultimate
- Ultimate -> Mega
- Child -> Rookie
- Baby I & II -> Training / In-training I & II
- Evolution -> Digivolution
- Evolve(s) / Evolved -> Digivolve(s) / Digivolved
- Jogress -> DNA
- Digimental -> Digi-egg
